# Yearbound gameplay redesign brief — "Structures" pass (10 September 2026)

Mission: rebuild every campaign stage as **genuinely distinct, structure-driven,
maximally hard** platforming. Replace copy-paste block fields with authored
set-pieces (windmill carousels, sluice currents, pendulum lanterns, ice rinks…)
that fit each day's named places. The owner verifies playability by hand; our
duty is that every required maneuver stays **inside the measured movement
envelope** and that the data remains fully valid.

## Hard constraints (do not violate)

1. **Edit only `content/layouts/MM-DD.json`.** Compiled `content/stages/` output
   is regenerated by the compiler. No script, test, doc or scene edits.
2. Per layout keep unchanged: `schema_version`, `day`, `identity`, `world_top`,
   `spawn`, `length`, `goal`, `journey`, `scenery`, `secret_areas`, and each
   section's `name`, `origin`, `width`, `visual`. You may rewrite a section's
   `lesson`, `signs` text, `intent`, and all content arrays (`platforms`,
   `hazards`, `zones`, `motes`, `checkpoints`, `decorations`, `route`).
3. Set top-level `"revision": 15` (save invalidation for the new geometry).
4. Keep the stage's total **mote count identical** (motes are save IDs; new
   positions are fine — put them on optional risk lines). Keep **checkpoint
   count identical** (4 for June days, as listed per stage; months 5–6).
5. 48 px grid: every platform/hazard x/y/w/h is a multiple of 48. Platform y+h
   ≤ 720, y ≥ world_top, x ≥ 0, x+w ≤ section width (section-local coords;
   the compiler adds the section origin).
6. Spawn, goal and every checkpoint must rest on solid ground/platform or in
   swimmable water, with no platform intersecting the 24×42 px body space
   above them (validator checks this).
7. Keep ≥ 50 `bramble` hazards per stage (easy — brutal stages are dense) and
   route `vertical_travel` ≥ 192 (journey stages).
8. Update each section's `route` so it traces the new intended solution using
   only the supported actions below. The physics bot will attempt it; design so
   it *can* pass, but human-verifiable possibility is the bar, not the bot.

## Movement envelope (measured, 60 Hz — your design limits)

- Run speed 340 px/s. Full jump rises ~111 px and covers ~220 px running.
  Medium hold ~77 px, short tap ~45 px. Full jump lasts ~0.67 s.
- Charge dash: launch 560–1180 px/s, burst 0.075–0.20 s, horizontal ×1.5.
  Reference gaps: 192 px medium charge; 384 px needs full charge + run-up.
  Diagonals normalised; total launch cap 1550 px/s.
- Coyote 0.10 s; input buffer 0.12 s; corner correction ≤ 8 px (not a climb).
- Spring impulse 840 (≈126 px free rise, more with held jump); up to 1200 ok.
- Crumble: 0.65 s of contact, gone, returns after 3 s. Compiler splits crumble
  platforms into 48 px tiles automatically.
- Ice: acceleration 640 / braking 160 — long slides; design braking room.
- Gravity 2800 up / 3200 down; updraft lift must exceed it (use −3650).
  Wind/current forces are accelerations; existing stages use 130–260.
- Fall boundary Y=825 (below screen); continuous base ground at Y=624 stays
  in every stage — lethality comes from brambles and height, not pits.
- Player body 24×42 px; position is at the feet. Goal triggers within 58 px.

## Difficulty rubric — "as hard as possible" but provably inside the envelope

Required-path targets (comfort values in parentheses):
- Running jump gaps **192–216 px** (comfort 150). Rises **96–108 px** (max 111).
- Dash gaps **336–384 px** with landings **48–96 px** wide (comfort 192).
- Overhead clearance above brambles on required jumps: **24–48 px**.
- Ceiling corridors 96 px tall sustained ≥ 480 px; short-hop rhythm sections.
- Timed hazard safe windows **0.9–1.2 s**; stagger phases so consecutive gates
  cannot be chained in one run.
- Crumble chains ≥ 3 tiles with rest islands ≤ 96 px.
- Spring chains ≥ 3 in a row, targets moving or ≤ 96 px wide.
- Ice lanes with braking islands ≤ 96 px of stone.
- No single-frame tricks: every input window ≥ ~2 frames (33 ms). No blind
  required jumps — telegraph with a mote, sign or decoration line.
- Punish failure with death (brambles) or costly recovery (current drift,
  swim detour), never with softlocks. After any fall the player must be able
  to climb back or die — test this mentally per drop.

## Mechanic vocabulary (exact JSON shapes)

Platforms (section-local): `{"x","y","w","h","kind",…}`
- `block` + `"material":"stone"|"hay"|"log"` — solid mass; heights 48–144.
- `wood` — thin bridge (h 48); solid from below too → low ceilings.
- `ice` — slick. `spring` + `"power":840..1200` — auto-launch on landing.
- `crumble` — 0.65 s timer tiles. `moving` — see patterns below.

Hazards:
- `bramble`: `{"type":"bramble","x","y","w","h","direction":"up|down|left|right"}`.
  Wall spikes: rotate w/h. Keep 24–48 px clearance over required jumps.
- `blade`/`thorn`: `{"type":"thorn","x","y","r":24,"axis":"x|y","distance":D,"speed":S,"phase":P}`
  — swinging/orbiting circular hazard. Use as windmill blades, pendulums,
  seedheads. (Currently unused anywhere — a fresh silhouette.)
- `icicle`: `{"type":"icicle","x","y","r":16,"local":true,"period":2.4,"phase":0.0,"warning_seconds":1.35,"floor_y":624}`.
- `storm`: `{"type":"storm","x","y","w":48,"h":H,"period":P,"active_seconds":A,"warning_seconds":W,"phase":Ph}`
  — vertical lightning lane. Rule: period > active+warning, warning ≥ 0.5.
  Brutal: period 2.8–3.6, active 0.5, warning 0.7 → crossing window 1.6–2.4 s.

Zones:
- `wind`: `{"type":"wind","x","y","w","h","force":[FX,0]}` (+`"pulse":true`).
- `updraft`: force `[0,-3650]`; start corridors below the takeoff point.
- `current` (shallow conveyor): `{"type":"current","x","y","w","h","submerged":true,"force":[130,-30]}`.
- `water` (physical swim): `{"type":"water","x","y","w","h","swimmable":true}`.

Moving platform (two forms; always include `axis`,`distance`,`speed` fallback):
- Simple ping-pong: `{"kind":"moving","axis":"x","distance":336,"speed":1.0,…}`.
- Authored loop: `"motion_path":[[0,0],[0,-336],[528,-336],[528,0]]` (waypoint
  offsets; repeat a point to dwell there), `"motion_seconds":8`,
  `"motion_phase":0` (seconds offset into the loop), and a unique
  `"track_id":"MM-DD-N"` per platform (route `board`/`ride` reference it).

Route actions (each waypoint `{"at":[x,y],"action":…}`, section-local):
`start`, `walk`, `jump`, `short`, `drop`, `dash`, `skate`, `bounce`,
`spring_land`, `swim`, `board`/`ride` (+`track_id`), `flow_enter`,
`flow_exit` (+`shaft_x`), `timed`/`weather`/`pendulum` (+`gate_x` = hazard x).

## Structure library (compose these; invent more in the same spirit)

- **Carousel** (windmill/waterwheel): 4 moving platforms w=144 on one diamond
  `motion_path` (`R≈240–336`), shared `motion_seconds`, phases 0/T4/T2/3T4;
  optional `thorn` hub blades. Ride quarter-turns, hop blade gaps.
- **Ferry**: long moving platform over swimmable water; storm gates mid-crossing.
- **Sluice**: narrow corridor of opposing `current` tongues over bramble beds.
- **Updraft chimney**: vertical shaft, `updraft` lift, side ledges to catch.
- **Ice rink**: ice lanes ending at ≤96 px stone braking islands before spikes.
- **Crumble causeway**: ≥3-tile crumble spans, no mid-chain rest.
- **Spring canyon**: chained springs, mid-air dash redirect onto next stalk.
- **Storm lanes**: staggered-phase lightning grid with cover blocks.
- **Pendulum gallery**: thorn pendulums over a walkway; read the swing.
- **Icicle gallery**: staggered-period falling ice over a crossing.
- **Convoy**: 2–3 platforms on the same `motion_path`, different phases —
  jump carriage to carriage while the train moves.
- **Roof run**: down-bramble ceilings + `roof_jump` windows between beams.
